# Provider compliance

This repository uses GitHub and the public npm registry as declared providers.
Repository workflows use public Buildchain reusable workflows. Provider access
must follow the provider's terms and use least-privilege credentials.

No credential values, access tokens, private logs, billing records, or private
provider responses belong in source, fixtures, reports, build artifacts, or
issues. Release evidence may record public repository coordinates, source
commits, package versions, workflow runs, and content roots.
